# สาธิตส่งงาน

1. รันตาม README และ `npm run seed:demo`; เปิด http://localhost:8080.
2. Reporter แจ้งปัญหาพร้อมรูปและสถานที่ เก็บเลขที่เรื่อง.
3. Admin ตรวจรายละเอียด เปลี่ยนหมวดหมู่และมอบหมายงานอาคารและสถานที่.
4. Staff เปิดคิว กดเริ่มงาน แนบรูปหลังแก้ไขแล้วส่งงาน.
5. Reporter ดู timeline ขอแก้ไขใหม่พร้อมเหตุผล ให้ Staff ส่งงานใหม่ แล้วกดยืนยันปิดงาน.
6. เปิดการแจ้งเตือน แสดงสถานะ event และโหมดสาธิตที่บันทึกโดยไม่ส่งอีเมลจริง. Gmail เปิดได้เมื่อตั้งค่า OAuth ตามคู่มือ.
7. Admin เปิด analytics กรองวันที่/หน่วยงาน และตรวจ MTTR กับจุดที่แจ้งบ่อย.
8. Guest สอง browser profiles ทดสอบว่า Guest อีกคนอ่านเลขที่เรื่องเดียวกันไม่ได้.
9. `npm run test:recovery` แสดง broker outage/recovery และจำลองงานเกิน 7 วันเพื่อทดสอบ auto-close. Script ใช้เฉพาะ project local `fondue-demo`.

บัญชีและรหัสสาธิตดู README. เก็บ `test-results/` เป็นหลักฐาน; อ้างว่าผ่านเฉพาะการทดสอบที่รันจริง.
